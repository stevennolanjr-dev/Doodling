LCN DEFAULTS (IF UNKNOWN)
Concrete: L-value = 40. Asphalt: Thickness = 20. (Note 2)
ICAO adopted the Aircraft Classification Rating / Pavement Classification Rating (ACR-PCR) method in 2020 as a replacement for ACN-PCN. Full applicability was scheduled for 28 Nov 2024.

Key differences: ACR-PCR uses layered elastic analysis instead of the older CBR/Westergaard methods. It considers the full traffic mix and lateral wander rather than just the critical aircraft. There is no mathematical conversion between PCN and PCR values.

The USAF AFTTP 3-3.C-17 (Jul 2025) still uses ACN-PCN. This tool uses AFTTP data and remains operationally valid for USAF mission planning. EASA has deferred EU implementation. Transition timelines vary by nation.

Operational Notes (AFTTP 3-3.C-17, Table 3.1)

  • Data from 1C-17A-1-1, Ch 10 "Support Area Operations"
  • No CG limitations applied. FWD CG <32% requires TO check
  • Normal tire PSI: 144 (main), 160 (nose). See TO for reduced pressures
  • Values >447K: check 1C-17A-1-1 Sec 5 for SPRO limits
  • Note 1: Overload <5% annual. Asphalt +10%, Concrete +5% PCN
  • Note 2: Use L=40/Thickness=20 if unknown. Overload +25% (~1 flt/day)
  • Note 3: Prior permission required when ACN exceeds published PCN
  • ACN values interpolated linearly between OEW and MRW (ICAO method)
  • COMFAA known anomaly: C-17 rigid ACN can invert on high subgrades. Use TO values.
  • Interpolated GW values shown between table data points
